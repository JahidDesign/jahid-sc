# 🌐 Personal Portfolio – React + Vite

Welcome to my **personal portfolio website**, built using **React + Vite** — a fast, modern, and developer-friendly setup.  
This portfolio showcases my **skills, featured projects, and professional background** with a **responsive design, smooth animations, and bilingual support (English & Bangla)**.

---

## 🚀 Tech Stack

| Category | Technology |
|-----------|-------------|
| ⚛️ Frontend | React + Vite |
| 🎨 Styling | Tailwind CSS |
| 🎬 Animations | Framer Motion |
| 🧭 Routing | React Router DOM |
| ☁️ Backend / Hosting | Firebase |
| 🧠 Others | SweetAlert2, EmailJS, i18next (for multilingual support) |

---

## 🧩 Features

✅ Responsive & modern UI design  
✅ Bilingual support (English & Bangla)  
✅ Dynamic project showcase with live previews  
✅ Contact form integrated with Firebase / EmailJS  
✅ SEO-friendly titles & meta descriptions  
✅ Smooth page transitions using Framer Motion  
✅ Light and fast build with Vite
